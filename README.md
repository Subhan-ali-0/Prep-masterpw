
# Prep Master

## Installation

1. Install Node.js 18 or newer.
2. Open terminal in project folder.
3. Run:

npm install

4. Start website:

npm start

5. Open:

http://localhost:3000

## Features

- Automatic batch loading
- Batch search
- Study button
- Enroll system
- My Batches
- Community live chat
- Username system
- AI Doubts Support
- Telegram button
- White theme
- Mobile responsive design
